🍃 GanjaFlare 遊び方・解説

🎯 基本の育て方

  • 餌やり … エナジー +1（初期10回）
  • スモーク … エナジー +0.5（初期20回）
  • 回数切れは 100 GANJA POINT で追加購入
  • 猫をタップすると撫でて機嫌が上がる

⭐ レベルアップ

  • 経験値（EXP）が 100 貯まるごとにレベルアップ
  • EXPは主にミニゲームでネズミを倒して獲得
  • グレー=5 / イエロー=15 / ブルー=30 / ピンク=150 / ボス撃破=大量EXP

✨ 進化

  • 特定レベルで「進化」ボタンが押せる
  • 進化レベル：5 / 10 / 20 / 30 / 50 / 80 / 100 / 200 / 500 / 1000 / 1500 以降は+500ごと
  • 進化ごとに：ビーム初期数+3、必要発数-1、移動速度×1.25、ビーム威力×1.25、タイムストップ+1

🐭 ミニゲーム / ステージ

  • 現在の STAGE でプレイ（トップに表示）
  • 通常ステージ：制限時間なし。獲得ポイント 400 でクリア
  • 失敗条件：ビーム切れ または エナジー0
  • クリアボーナス：ノーダメ +100 GP／残エナジー50〜90% +50 GP
  • ステージが上がるほど敵の数・出現頻度が増加
  • クリア後「セーブして次のステージへ」「セーブしてやめる」を選択
  • 冒頭に「ステージ○」を2秒表示
  • 初期プレイ回数 5回（1時間に1回復）／200 GPで+3回
  • 初期ビーム 30発（進化で+3）
  • グレー3体→🌱ビーム+3／ピンク20秒・右→左・EXP150／葉っぱ25秒・左→右
  • 葉っぱ1回→ビーム2本／2回→扇形15°3本＋猫デザイン変化
  • 操作：←→ / BEAM短押し・長押し大ビーム / ⏱タイムストップ

👑 ボス戦（5ステージごと）

  • STAGE 5,10,15… でボス出現。冒頭「Alert！」点滅2秒
  • 制限時間 300秒
  • ボスHP：STAGE5=100 / 10=150 / 15=200 …（+50）
  • ビーム大量発射・大きめ。ピンク＆葉っぱも出現
  • 撃破で大量EXP＆クリア

🤖 進化と見た目

  • 進化するごとにトップの猫がサイバー調に変化
  • ネオンの発光・リング演出が強化されます

🪙 GANJA POINT

  • ミニゲームのEXPに応じて獲得
  • 餌・スモーク回数やミニゲーム回数の購入に使う

⏳ エナジー減衰

  • リアル時間で 24時間ごとに半分 まで減衰します
  • こまめに餌・スモークで維持しよう

🎰 スロットメダル & スロット

  • 直近3日の平均エナジーが 70%以上 でメダル 1枚
  • メダル 3枚 でスロット1回
  • 🐱×3 → 300GP　／　7️⃣×3 → 150GP
  • 🍒×3 → 100GP　／　BAR×3 → 50GP

💾 セーブ / ロード

  • 進行状況はブラウザに自動保存されます
  • 「💾 セーブ」「📂 ロード」ボタンでも手動操作可能
  • 「🗑 セーブリセット」で最初からやり直せます
  • 同じ端末・同じブラウザでのみ有効です
